# Roadmap

Roadmap items are hypotheses until validated by real, privacy-safe user reports.

## v0.1 — auditable scalar bridge

- [x] CSV and XLSX import
- [x] deterministic scalar comparison mapping
- [x] stable input, unit, metrology, and uncertainty diagnostics
- [x] in-browser DCC 3.3.0 XSD validation
- [x] native `xmllint` release cross-check
- [x] English/Chinese UI and audit report
- [ ] public Pages deployment and first signed release

## v0.2 — reusable mappings

- [ ] interactive column mapping and exportable mapping templates
- [ ] multi-language certificate content
- [ ] multiple calibrated items
- [ ] richer unit dictionary and conversion provenance
- [ ] accessible error location and XML preview

## v0.3 — metrology profiles

- [ ] repeated-series observations
- [ ] spatial/temporal temperature-field profile
- [ ] explicit uncertainty-budget representation
- [ ] cross-tool interoperability pack and published compatibility matrix

## Maturity gates

A stable v1.0 requires documented privacy-safe trials from at least three
independent workflows, no unresolved critical validation discrepancy, a
reproducible release, and a published migration policy.
