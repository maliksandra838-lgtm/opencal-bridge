# Governance

OpenCal Bridge currently uses a maintainer-led model.

The primary maintainer is responsible for Issue triage, review, release notes,
dependency and schema updates, security response, documentation accuracy, and
preserving the distinction between structural validation and metrological
conformity.

Decisions should be evidence-led and recorded publicly in Issues or pull
requests. Breaking changes to the input contract, diagnostic codes, generated
XML, schema version, or privacy model require a documented migration path.

Regular contributors may be invited as reviewers or maintainers after a history
of technically sound, respectful contributions. No contributor, user,
institution, Star, or adoption claim will be fabricated or exchanged for project
benefits.
