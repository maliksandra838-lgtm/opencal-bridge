# OpenCal Bridge alpha.1 compatibility matrix

This document records a reproducible, privacy-safe tool-level check of the
synthetic DCC fixtures shipped with OpenCal Bridge `v0.1.0-alpha.1`.

It is not a PTB, BIPM, accreditation-body, laboratory, or vendor endorsement.
It also does not prove that a certificate is fit for issue. Independent
laboratory workflows and downstream viewers still need real-world reports.

## Test input

| Fixture | Purpose | Data boundary |
| --- | --- | --- |
| `tests/fixtures/generated-mass.xml` | scalar mass comparison | synthetic only |
| `tests/fixtures/generated-temperature.xml` | scalar temperature comparison | synthetic only |

Both files are generated by the repository's deterministic fixture script and
validated against the bundled PTB DCC 3.3.0, PTB D-SI 2.2.1, and XMLDSig
schemas. The tested commit was `51c6481a5a530ed600f9602904fd75c9960c25b9`.

## Results recorded on 2026-08-21 (Asia/Tokyo)

| Path | Tool/version | Result | Scope and limitation |
| --- | --- | --- | --- |
| Browser validator path | `xmllint-wasm 5.3.0` | PASS: mass + temperature | Same validator path used by the shipped browser application; no network schema resolution. |
| macOS native validator path | `xmllint` with libxml2 `2.9.13` | PASS: mass + temperature | Native command-line XSD validation with the repository XML catalog and `--nonet`. |
| Python validator path | `xmlschema 4.2.0` | PASS: mass + temperature | Offline schema validation with local PTB schemas and explicit namespace locations. This was run in a temporary environment and is not a project runtime dependency. |

## Reproduction

From the repository root:

```sh
npm run check
```

The full check regenerates the synthetic examples, verifies schema hashes,
runs the six unit tests, builds the application, regenerates both XML fixtures,
and validates them through the browser/WASM and native `xmllint` paths.

The Python path can be reproduced with `xmlschema 4.2.0` and these local
namespace locations (the command is intentionally kept outside `package.json`;
the application remains browser-only and offline):

```python
from pathlib import Path
import xmlschema

root = Path.cwd()
locations = [
    ("https://ptb.de/si", root / "public/schemas/ptb/d-si/2.2.1/SI_Format.xsd"),
    ("http://qudt.org/vocab/", root / "public/schemas/ptb/d-si/2.2.1/qudt/quantitykind.xsd"),
    ("http://www.w3.org/2000/09/xmldsig#", root / "public/schemas/ptb/xmldsig/xmldsig-core-schema.xsd"),
]
schema = xmlschema.XMLSchema(
    root / "public/schemas/ptb/dcc/3.3.0/dcc.xsd",
    locations=locations,
    allow="local",
)
for fixture in sorted((root / "tests/fixtures").glob("generated-*.xml")):
    assert schema.is_valid(fixture), fixture
```
