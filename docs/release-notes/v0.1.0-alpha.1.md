OpenCal Bridge's first public alpha turns a constrained CSV or XLSX calibration
table into deterministic PTB DCC 3.3.0 XML and a human-readable audit report.
Everything runs locally in the browser; no account, API key, or data upload is
required.

## Included

- English and Simplified Chinese interface and documentation.
- Synthetic mass and temperature examples.
- Stable diagnostic codes for input and metrology-semantic checks.
- In-browser XSD validation with the vendored PTB DCC 3.3.0 schema set.
- Downloadable DCC XML and self-contained audit HTML.
- A self-contained offline ZIP with a published SHA-256 checksum.

## Verification

- 6 deterministic unit tests passed.
- Both generated fixtures passed the WASM validator and native xmllint.
- GitHub CI, CodeQL, and Pages deployment passed for the tagged commit.
- The published ZIP was downloaded again and matched SHA256SUMS.txt.

## Important alpha limits

This release is for evaluation and interoperability testing. XSD-valid means
structurally valid only; it is not proof of metrological, accreditation, legal,
or contractual compliance. OpenCal Bridge is not affiliated with or endorsed by
PTB, BIPM, or DKD.

For compatibility results, use synthetic or redacted data and report them in
issue #8. Product feedback and reproducible failures are welcome through the
repository's structured issue forms.
